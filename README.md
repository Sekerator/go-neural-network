# go-neural-network

Небольшая библиотека полносвязных нейронных сетей на чистом Go без внешних зависимостей.

Поддерживает два способа обучения:

- **Эволюционный** — популяция сетей, отбор лучших, мутации и скрещивание.
- **Обратное распространение ошибки** — классический градиентный спуск для одной сети.

## Возможности

| | |
|---|---|
| 🧠 **Архитектура** | Любое число входов, выходов и скрытых слоёв произвольного размера |
| 📈 **Активация** | `tanh` на всех скрытых и выходных нейронах, выход в диапазоне `(-1, 1)` |
| 🧬 **Эволюция** | Элитизм, мутация весов и смещений, скрещивание с лучшими сетями |
| 🔁 **Backprop** | Стохастический градиентный спуск по MSE |
| ⚡ **Параллельность** | Создание популяции и шаг эволюции выполняются в горутинах |
| 🧹 **Без зависимостей** | Только стандартная библиотека |

## Требования

- Go **1.22** или новее

## Структура проекта

```
.
├── internal/
│   ├── handler.go                 # Handler — точка входа библиотеки
│   ├── evolution_handler.go       # популяция и эволюционное обучение
│   ├── backpropagation_handler.go # обучение обратным распространением
│   ├── models/                    # Neuron, Synapse
│   └── services/                  # сеть Nn, конфигурация, мутации, скрещивание, backprop
├── main.go                        # демо: сравнение двух чисел
└── train-data.csv                 # обучающие данные для демо
```

> [!NOTE]
> Сейчас пакеты лежат в `internal/`, а модуль называется `neural_network`.
> Go не разрешает импортировать `internal`-пакеты из другого модуля, поэтому
> для подключения в сторонние проекты публичные пакеты нужно вынести из `internal/`,
> а модулю задать путь `github.com/sekerator/go-neural-network`.

## Быстрый старт

### Эволюционное обучение

```go
package main

import (
	"fmt"
	"math"

	"neural_network/internal"
	"neural_network/internal/services"
)

func main() {
	handler := internal.NewHandler(services.NnInitData{
		InputNeuronCount:  2,
		HiddenLayerCount:  2,
		HiddenNeuronCount: []int{6, 4},
		OutputNeuronCount: 1,

		MutationBiasChance:   10,
		MutationWeightChance: 10,
		MutationBiasRate:     0.05,
		MutationWeightRate:   0.05,
	})

	brains, err := handler.CreateEvolutionNn(1000)
	if err != nil {
		panic(err)
	}

	trainData := [][][]float64{
		{{3, 5}, {1}},
		{{5, 3}, {-1}},
		{{4, 4}, {0}},
	}

	for range 100 {
		scoreBoard := make(map[int]float64, len(brains))
		for id := range brains {
			scoreBoard[id] = 0
		}

		for id, brain := range brains {
			for _, sample := range trainData {
				result, err := brain.GetResult(sample[0])
				if err != nil {
					panic(err)
				}
				if math.Round(result[0]) == sample[1][0] {
					scoreBoard[id]++
				}
			}
		}

		if err := handler.TrainEvolutionNn(scoreBoard); err != nil {
			panic(err)
		}
	}

	result, _ := brains[0].GetResult([]float64{2, 7})
	fmt.Println(result)
}
```

> [!IMPORTANT]
> `scoreBoard` должен содержать оценку **для каждой** сети популяции.
> **Больше — лучше.** Сеть, которая ни разу не ответила верно, всё равно должна
> присутствовать в `scoreBoard` со значением `0`.

### Обратное распространение ошибки

```go
handler := internal.NewHandler(services.NnInitData{
	InputNeuronCount:  2,
	HiddenLayerCount:  1,
	HiddenNeuronCount: []int{4},
	OutputNeuronCount: 1,

	MutationBiasRate:   0.05,
	MutationWeightRate: 0.05,
})

if err := handler.CreateBackpropagationNn(); err != nil {
	panic(err)
}

trainData := [][][]float64{
	{{3, 5}, {1}},
	{{5, 3}, {-1}},
	{{4, 4}, {0}},
}

if err := handler.TrainBackpropagationNn(10000, trainData); err != nil {
	panic(err)
}

result, err := handler.GetResultBackpropagationNn([]float64{2, 7})
```

Формат обучающих данных — `[][][]float64`, где каждый пример — это пара `{вход, ожидаемый выход}`:

```go
{ {x1, x2, ...}, {y1, y2, ...} }
```

## Конфигурация сети

`services.NnInitData`:

| Поле | Тип | Описание |
|---|---|---|
| `InputNeuronCount` | `int` | Число входных нейронов. Должно быть `> 0` |
| `HiddenLayerCount` | `int` | Число скрытых слоёв. Может быть `0` — тогда вход соединён с выходом напрямую |
| `HiddenNeuronCount` | `[]int` | Размер каждого скрытого слоя. Длина должна совпадать с `HiddenLayerCount`, все значения `> 0` |
| `OutputNeuronCount` | `int` | Число выходных нейронов. Должно быть `> 0` |
| `MutationBiasChance` | `int` | Вероятность мутации смещения нейрона, в процентах `0–100`. Только для эволюции |
| `MutationWeightChance` | `int` | Вероятность мутации веса синапса, в процентах `0–100`. Только для эволюции |
| `MutationBiasRate` | `float64` | Эволюция — сила мутации смещения. Backprop — шаг обучения для смещений |
| `MutationWeightRate` | `float64` | Эволюция — сила мутации веса. Backprop — шаг обучения для весов |

Проверить конфигурацию заранее можно через `NnInitData.Validate()`.

## Справочник API

### `internal.Handler`

| Метод | Описание |
|---|---|
| `NewHandler(data NnInitData) *Handler` | Создаёт обработчик с заданной конфигурацией |

#### Эволюция

| Метод | Описание |
|---|---|
| `CreateEvolutionNn(count int) (map[int]*Brain, error)` | Создаёт популяцию из `count` сетей с id от `0` до `count-1`. При ошибке текущая популяция не меняется |
| `TrainEvolutionNn(scoreBoard map[int]float64) error` | Выполняет одно поколение эволюции по оценкам сетей |
| `CrossEvolutionNn(intoId, fromId, chance int) error` | Заменяет сеть `intoId` результатом скрещивания с `fromId`. `chance` — вероятность взять ген донора, в процентах |
| `SetInputAllEvolutionNn(input []float64) error` | Подаёт один и тот же вход на все сети популяции |

#### Backpropagation

| Метод | Описание |
|---|---|
| `CreateBackpropagationNn() error` | Создаёт и инициализирует сеть |
| `TrainBackpropagationNn(iterationCount int, data [][][]float64) error` | Проходит по всем примерам `iterationCount` раз, обновляя веса после каждого примера |
| `GetResultBackpropagationNn(input []float64) ([]float64, error)` | Возвращает выход сети для заданного входа |

### `internal.Brain`

Одна сеть эволюционной популяции.

| Член | Описание |
|---|---|
| `ID int` | Идентификатор сети в популяции |
| `GetResult(input []float64) ([]float64, error)` | Возвращает выход сети |
| `Mutate() error` | Случайно мутирует веса и смещения сети |

### `services`

Низкоуровневые типы, на которых построен `Handler`.

| Тип / функция | Описание |
|---|---|
| `NnInitData.Validate() error` | Проверяет конфигурацию |
| `NewNn(data) *Nn`, `(*Nn).Init() error` | Создание сети и построение топологии со случайными весами |
| `(*Nn).SetInput(input) error` | Подаёт вход на входные нейроны |
| `(*Nn).GetResults() []float64` | Прямой проход и значения выходных нейронов |
| `(*Nn).Clone() *Nn` | Глубокая копия сети |
| `NewEvolutionNn(data)`, `(*EvolutionNn).Mutate()` | Сеть для эволюции и её мутация |
| `Cross(nn1, nn2 EvolutionNn, chance int)` | Новая сеть — копия `nn1`, в которой каждый ген с вероятностью `chance`% взят из `nn2` |
| `NewBackpropagationNn(data)`, `(*BackpropagationNn).Train(expected)` | Сеть для backprop и один шаг обучения |

## Как это работает

### Топология

Сеть полносвязная: каждый нейрон слоя соединён с каждым нейроном следующего слоя.
Начальные веса и смещения выбираются случайно из диапазона `[-0.5, 0.5)`.

```
вход ──► скрытый слой 1 ──► … ──► скрытый слой N ──► выход
```

Значение нейрона: `tanh(Σ(вход × вес) + смещение)`.

### Нормализация входа

Перед подачей вход делится на максимальное по модулю значение, так что все входы
попадают в `[-1, 1]`. Исходный слайс при этом не изменяется.

```
[3, 5]     → [0.6, 1]
[-8, 2]    → [-1, 0.25]
```

### Поколение эволюции

`TrainEvolutionNn` сортирует сети по убыванию оценки и делит популяцию на три группы:

| Группа | Доля | Что происходит |
|---|---|---|
| 🏆 Лучшие | первые 10% (минимум одна сеть) | Остаются без изменений |
| 🔧 Средние | до 50% | Мутируют |
| 🧬 Худшие | оставшиеся 50% | Заменяются скрещиванием с одной из лучших сетей (`chance = 50`) |

**Мутация.** Для каждого смещения с вероятностью `MutationBiasChance`% к нему прибавляется
случайное значение из `[-MutationBiasRate/2, MutationBiasRate/2)`. Для весов — аналогично
с `MutationWeightChance` и `MutationWeightRate`.

### Обратное распространение ошибки

- Функция потерь — среднеквадратичная ошибка.
- Ошибка выходного нейрона: `(y − t) · (1 − y²)`.
- Ошибка скрытого нейрона: `(1 − h²) · Σ(вес · ошибка следующего нейрона)`.
- Веса обновляются после каждого примера: `w −= rate · ошибка · вход`.
- Ожидаемые значения вне `[-1, 1]` сжимаются через `tanh`. Переданный слайс не изменяется.

## Потокобезопасность

- `Handler` не предназначен для одновременного использования из нескольких горутин.
- `Brain.GetResult` можно вызывать параллельно для **разных** сетей, но не для одной и той же.
- Не вызывайте `TrainEvolutionNn` одновременно с `GetResult` — дождитесь окончания оценки популяции.

## Демо

`main.go` обучает популяцию сравнивать два числа на данных из `train-data.csv`.
Каждая строка — `a;b;результат`, без заголовка:

```
-7196;-7269;-1
8383;8480;1
7712;7712;0
```

| Результат | Значение |
|---|---|
| `1` | второе число больше |
| `0` | числа равны |
| `-1` | первое число больше |

Запуск:

```bash
go run .
```

Программа спросит число итераций обучения, затем пары чисел для проверки.
Для выхода введите `1515` дважды.
